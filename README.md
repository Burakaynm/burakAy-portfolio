# Burak Ay Portfolio

A professional personal portfolio website built to present my software development experience, technical skills, and selected projects.

## Overview

This portfolio website was developed as a modern, responsive, and maintainable frontend project. It showcases my background as a Software Engineer and Full-Stack Developer, including professional experience, technical skills, and selected software projects.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Vercel

## Features

- Responsive single-page layout
- Professional hero section
- About section
- Technical skills section
- Experience timeline
- Project cards with live demo and GitHub links
- Contact section with phone, mail, GitHub, LinkedIn, and CV links
- Reusable component-based structure
